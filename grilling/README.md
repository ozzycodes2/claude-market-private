# grilling

Relentless interviews that stress-test a plan, decision, or design before you commit
to it — and, for larger work, a way to map out more than one session can hold.

## Skills

| Skill | What it does |
|-------|--------------|
| `grilling` | The core interview — grills you relentlessly about a plan, decision, or idea to sharpen your thinking. Triggers on any "grill" phrase. |
| `grill-me` | A quick trigger for a relentless interview to sharpen a plan or design. |
| `grill-with-docs` | Grilling that also produces docs — ADRs and a glossary — as decisions crystallize. |
| `wayfinder` | Plan work too large for one agent session as a shared map of decision tickets on your issue tracker, resolved one at a time until the path is clear. |

## Usage

```
> grill me on this migration plan
> grill this design and write ADRs as we go
> wayfinder: plan the multi-quarter platform migration
```

Each skill can also be invoked explicitly, e.g. `/grilling:grill-me`.
